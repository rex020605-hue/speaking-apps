# 말로 · Mallo

중학교 입학을 앞둔 학생이 일상 주제로 영어를 말해보는 웹 앱입니다. 현재는 **외부 AI API를 연결하지 않는 검토용 버전**입니다. API 키나 로그인 없이 실행할 수 있으며, 음성과 답변을 외부 서비스에 전송하지 않습니다.

## 다운로드해서 여는 미리보기

이 채팅의 Markdown 문서 뷰어와 실행형 앱 미리보기는 서로 다릅니다. 별도 서버 없이 앱을 보려면 다음 명령으로 HTML 파일을 만드세요.

```sh
npm run build:preview
```

생성된 [`preview/mallo.html`](preview/mallo.html)을 내려받아 Chrome 또는 Edge에서 직접 열면 됩니다. JavaScript·스타일·음성·녹음 처리 파일이 모두 포함되어 별도 경로나 API가 필요하지 않습니다. 이 파일은 기기에 설치된 글꼴을 사용합니다. 뷰어에서 JavaScript를 제한하면 파일을 내려받아 브라우저에서 직접 여세요.

제한된 뷰어에서는 마이크나 영구 저장소가 차단될 수 있습니다. 이때는 샘플·직접 입력·현재 화면의 표현 노트로 체험할 수 있으며, 화면에 제한을 안내합니다. 실제 마이크는 기기와 브라우저 권한에 따라 사용할 수 있습니다.

[PC·모바일 화면 설명과 이미지](docs/REVIEW.md)는 실행형 미리보기가 아닌 참고 문서입니다.

## 실행

Node.js 24 이상이 필요합니다.

```sh
cd /workspace/speaking-apps
npm ci
npm run dev
```

개발 서버의 기본 포트는 5173입니다. 마이크는 HTTPS 또는 localhost에서 동작합니다. 마이크 권한을 허용하지 않아도 직접 입력과 샘플 연습은 사용할 수 있습니다.

```sh
npm run build   # 타입 검사 + 정적 빌드 → dist/
npm start       # 빌드 결과를 로컬 4173 포트에서 확인
```

위 로컬 명령은 배포하지 않습니다. 소유자의 배포 요청에 따라 `.github/workflows/deploy-pages.yml`에 GitHub Pages 배포를 준비했습니다. GitHub Pages가 GitHub Actions 소스로 활성화되면 `main`에 푸시할 때 잠금 의존성 설치·단위 테스트·빌드 후 사이트를 게시합니다. 기존 클라우드 체크아웃을 그대로 사용하며 새 Git worktree는 필요하지 않습니다.

## 지금 사용할 수 있는 기능

- 취미·학교·친구·음식·주말, 5개 주제와 질문 15개
- 질문 듣기, 한국어 해석, 시작 표현과 어휘 힌트
- 최대 30초 음성 녹음, 즉시 재생, 취소, 다시 녹음
- 완료 전 처음 녹음과 다시 녹음을 번갈아 듣는 비교 (동시 재생 방지)
- 직접 문장 입력, 내 답변과 예시 문장 비교, 자기 점검
- 미리 작성된 샘플 답변의 문법 교정 예시와 자연스러운 표현
- 예시 문장 듣기, 다시 말하기, 연습 완료와 다음 질문
- 브라우저에 저장하는 연습 기록·표현 노트, 각각 삭제 또는 저장소 초기화
- 완료 전 주제 변경·다시 시작·샘플 전환 시 유지/완료 후 이동/폐기 선택과 새로고침 경고
- 모바일 화면과 키보드 조작, 마이크/저장소 오류 안내

**샘플 피드백은 실제 학생의 답변을 분석한 결과가 아닙니다.** 화면에 출처를 표시하며, 직접 작성한 답변에 샘플 교정을 적용하지 않습니다. 자동 받아쓰기·개인별 문법 교정·발음 평가는 아직 제공하지 않습니다. 오늘의 말하기 목표에는 완료한 음성 연습만 포함하며, 입력 연습과 샘플은 별도로 집계합니다. 한 연습에서 녹음을 다시 해도 완료 시 한 번만 집계합니다.

## 음성과 기록

- 녹음은 Web Audio의 AudioWorklet으로 캡처한 단일 채널 PCM WAV입니다. 최대 30초까지만 모읍니다.
- 원본 음성은 현재 탭 메모리에만 존재합니다. 다시 말하기를 하면 처음 녹음과 최근 녹음을 비교하며, 완료·연습 전환·탭 종료 시 모두 지웁니다. 다른 탭으로 이동하면 진행 중인 녹음을 마무리합니다.
- 연습 완료 날짜, 질문, 입력한 문장과 저장한 예시 표현만 `mallo.practice.v1` 키로 localStorage에 저장합니다. 원본 음성과 blob URL은 저장하지 않습니다.
- 기록은 로그인 동기화 없이 해당 브라우저에만 남습니다. 연습 기록 → 기록 관리는 연습 기록만, 표현 노트 → 노트 비우기는 표현만 지웁니다. 최대 200개씩 보관합니다.
- 호환되지 않는 기존 저장 데이터는 자동으로 덮어쓰지 않습니다. 안내의 기록 초기화 버튼으로 명시적으로 지울 수 있습니다.
- 듣기는 기기 내 영어 TTS 음성을 우선 사용합니다. 원격 TTS 음성은 선택하지 않습니다. 기기 내 영어 음성이 없으면 앱에 포함한 MP3 30개를 사용합니다. 웹 폰트도 앱에 포함하므로 Google Fonts 등의 외부 요청이 없습니다.

## 검증

```sh
npm test
npm run test:e2e
npm run test:pages
npm run check
```

브라우저 테스트에는 Chromium이 필요합니다. `/usr/bin/chromium`이 있으면 사용하며, 다른 위치는 `CHROMIUM_PATH` 환경변수로 지정합니다. 그 외에는 Playwright에서 설치한 Chromium을 사용합니다. 실제 마이크 대신 Chromium의 가상 마이크로 녹음·PCM 파일·마이크 해제·자동 종료를 검증합니다. 테스트 서버는 4180 포트를 사용하며 테스트 종료 시 닫습니다.

단위 테스트는 PCM 인코딩, 저장 데이터 검증·복구, 실제 연습 집계, 음성 자산 누락, 미연결 AI 어댑터의 외부 요청 방지를 검사합니다. 브라우저 테스트는 샘플/직접 입력/녹음 흐름, 권한 거절, 저장/삭제, 320px·390px 화면, 재생 취소와 주제 변경을 검사합니다. 실제 휴대폰 기기에서의 마이크·스피커 확인은 별도로 필요합니다.

단일 HTML 미리보기는 외부 자산 서버 없는 문서와 `sandbox="allow-scripts"` 프레임에서도 검증합니다. 관리형 Chromium의 `file://` 접근은 관리자 정책으로 차단되어 직접 파일 열기는 이 환경에서 검증할 수 없습니다. 대신 생성된 HTML 원문을 로컬 테스트 응답과 제한된 프레임에 그대로 주입해 실행·음성·녹음을 검사합니다. 관리자 정책을 해제하거나 우회하지 않습니다.

## GitHub Pages 배포

정적 사이트의 빌드 출력은 `dist/`입니다. 저장소의 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다. `.github/workflows/deploy-pages.yml`이 `main` 푸시 또는 수동 실행 시 배포를 수행합니다. 이 저장소가 비공개인 경우 GitHub 요금제의 Pages 지원 여부도 확인해야 합니다. 자동 배포에는 별도 AI 키가 필요하지 않습니다.

프로젝트 하위 경로에서도 질문 음성과 녹음 worklet을 불러오도록 Vite의 `BASE_URL`을 사용합니다. 직접 빌드할 때는 다음처럼 확인할 수 있습니다.

```sh
npm run build -- --base=/speaking-apps/
npm start -- --base=/speaking-apps/
```

GitHub API 접속과 게시 결과 확인에는 `api.github.com` 및 `rex020605-hue.github.io` 네트워크 허용이 필요합니다. 환경 설정 초안 저장은 사이트 배포가 아니며, 실제 배포 성공은 Actions 실행 결과와 공개 HTTPS 응답으로 확인해야 합니다.

## 나중에 AI를 연결할 위치

`src/services/coach.ts`에 `SpeakingCoach` 인터페이스가 있습니다. 현재 구현은 요청을 보내지 않고 명시적인 미연결 오류를 반환합니다. 실제 연결 시에는 같은 출처의 서버 API를 추가하고 이 어댑터를 교체합니다.

1. 녹음 전송 전 명시적 동의를 받고, 서버에서 음성 형식·길이·요청 빈도를 제한합니다.
2. 음성 인식 결과를 학생에게 확인받은 뒤 문법과 표현을 검토합니다.
3. 발음 피드백은 실제 음성을 근거로 제공하며, 텍스트만으로 발음을 채점하지 않습니다.
4. 한 번에 중요한 개선점 한두 개만 제시하고, 맞는 문장을 억지로 교정하지 않습니다.
5. 원본 음성 보관 정책과 제공자의 미성년자 대상 이용 조건·무료 티어 데이터 사용 조건을 확인합니다.
6. API 키는 서버에만 두며 `VITE_` 변수나 프런트엔드 코드에 넣지 않습니다.

Gemini API를 검토했지만 연결하지 않았습니다. 이 환경에서는 공식 약관 페이지 접속이 네트워크 정책으로 차단되어 최신 조항을 확인하지 못했습니다. 학생용 실제 연결 전 [공식 약관](https://ai.google.dev/gemini-api/terms)을 확인하고 대상 연령에 적합한 제공자를 확정해야 합니다. 현재 앱 실행에는 Gemini 키가 필요하지 않습니다.

## 구조

```text
src/App.tsx             화면과 연습 흐름
src/styles.css          반응형 스타일
src/lib/audio.ts        로컬 녹음·WAV·음성 재생
src/lib/storage.ts      검증된 브라우저 기록
src/services/coach.ts   향후 서버 AI 연결 인터페이스
shared/catalog.ts      주제·질문·샘플 답변
shared/types.ts         공통 타입과 피드백 검증
public/audio/          포함된 질문·예시 음성
tests/                 단위·브라우저 테스트
```

음성 자산을 다시 만들려면 FFmpeg의 `flite` 필터가 있는 환경에서 `node scripts/generate-audio.mjs`를 실행합니다. 기본 실행에는 FFmpeg가 필요하지 않습니다. 포함된 음성은 로컬 합성 음성이며 외부 API로 생성하지 않았습니다.
